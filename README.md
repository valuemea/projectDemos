`@umijs/max` 模板项目，更多功能参考 [Umi Max 简介](https://umijs.org/docs/max/introduce)

## 可用脚本命令

`npm start` 项目启动命令

`npm run build` 打包构建项目

## 项目介绍

前端知识库，用于平时工作或学习的归纳总结，方便后期查阅复习。

### 项目搭建，初始化项目

技术栈：umi + react + antd + ts

使用 `npx create-umi@latest` 创建 umi + antd 的基础项目模板。清理多余文件，配置基础项目目录。

node 版本，需要是 18 或以上，创建项目时使用的版本是 18.18.0

### 创建 git 仓库并上传代码

```
  git add .
  git commit -m "init"
  git remote add origin git@github.com:valuemea/react-example-demos.git
  git branch -M main
  git push -u origin main
```
